# 🧩 Components

Components are the fundamental building blocks of a React application. Each component represents a specific part of the user interface.

## Examples
- Button
- Header
- Card
- Form

A React application is composed of many components working together.

---

## 🚀 Setting Up a React Project (create-react-app)

To start working with React, you need to create a ready-to-use project structure.

```bash
npx create-react-app my-app
cd my-app
npm start
