#Props, Key, React Developer Tools

| English                                                                   | Türkçe                                                                    |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **Props** are inputs passed from a parent component to a child component. | **Props**, parent component’ten child component’e gönderilen verilerdir.  |
| Props are read-only and cannot be modified by the child component.        | Props sadece okunur, child component tarafından değiştirilemez.           |
| Props enable reusable and dynamic components.                             | Props, tekrar kullanılabilir ve dinamik component’ler oluşturmayı sağlar. |
| Props are passed as attributes in JSX.                                    | Props, JSX içinde attribute olarak gönderilir.                            |
| Destructuring props improves readability and clean code.                  | Props destructuring kod okunabilirliğini artırır.                         |
| The `key` prop is required when rendering lists.                          | Liste render ederken `key` prop’u zorunludur.                             |
| `key` helps React identify which items have changed.                      | `key`, React’in hangi elemanın değiştiğini anlamasını sağlar.             |
| Keys must be unique among siblings.                                       | Key’ler aynı seviyedeki elemanlar arasında benzersiz olmalıdır.           |
| Using array index as key is discouraged.                                  | Array index’ini key olarak kullanmak önerilmez.                           |
| React Developer Tools allows inspecting component trees.                  | React Developer Tools component ağacını incelemeyi sağlar.                |
| You can inspect props and state via React DevTools.                       | React DevTools ile props ve state görüntülenebilir.                       |
| DevTools helps debug re-renders and prop issues.                          | DevTools re-render ve prop hatalarını debug etmeye yardımcı olur.         |
