# ⚛️ What Is React? | React Nedir?

## 🇹🇷 React Nedir?

React, kullanıcı arayüzleri (UI) oluşturmak için kullanılan **component (bileşen) tabanlı** bir JavaScript kütüphanesidir.  
Facebook (Meta) tarafından geliştirilmiştir ve özellikle **tek sayfa uygulamalar (SPA)** geliştirmede yaygın olarak kullanılır.

React’in amacı yalnızca ekran çizmek değildir.  
Asıl hedefi, **arayüzleri yönetilebilir, okunabilir ve sürdürülebilir** hale getirmektir.

---

## 🇬🇧 What Is React?

React is a **component-based** JavaScript library used to build user interfaces (UI).  
It was developed by Facebook (Meta) and is widely used for building **single-page applications (SPA)**.

React’s goal is not just to render UI, but to make interfaces **manageable, readable, and scalable**.

---

## 🧠 React’in Felsefesi | React Philosophy

### 🇹🇷 React’in Temel Felsefesi

React şu düşünce üzerine kuruludur:

> **Büyük ve karmaşık arayüzleri, küçük ve anlamlı parçalara böl.**

Bu yaklaşım sayesinde:
- Her component tek bir sorumluluğa sahiptir
- Kod tekrar kullanılabilir olur
- Değişiklikler tüm sistemi bozmaz
- Büyük projeler daha kolay yönetilir

React, her şeyi tek bir dosyada yazma yaklaşımını reddeder.  
Bunun yerine **parçala, yönet, birleştir** felsefesini benimser.

---

### 🇬🇧 Core Philosophy of React

React is built on the following idea:

> **Break large and complex interfaces into small, meaningful pieces.**

This approach allows:
- Each component to have a single responsibility
- Code to be reusable
- Changes to remain isolated
- Large projects to stay manageable

React rejects monolithic UI structures and embraces a **divide, manage, and compose** philosophy.

---

## ⚛️ React Sembolü | React Symbol

### 🇹🇷 React Sembolü Ne Anlama Gelir?

React logosundaki ⚛️ sembolü, **atomu** temsil eder.  
Bu sembol bilinçli olarak seçilmiştir çünkü React’in düşünce yapısını yansıtır.

- Atom, maddenin en küçük yapı taşıdır
- Component, React uygulamasının en küçük yapı taşıdır
- Küçük parçalar birleşerek büyük bir yapı oluşturur

> Atomlar nasıl birleşip molekülleri oluşturuyorsa,  
> component’ler de birleşerek React uygulamasını oluşturur.

---

### 🇬🇧 What Does the React Symbol Mean?

The ⚛️ symbol in the React logo represents an **atom**.  
It was intentionally chosen to reflect React’s core design principles.

- An atom is the smallest unit of matter
- A component is the smallest unit of a React application
- Small parts combine to form a complete structure

> Just as atoms form molecules,  
> components come together to build a React application.
