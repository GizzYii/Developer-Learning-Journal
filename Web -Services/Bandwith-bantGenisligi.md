## 🌐 Bandwidth  
## 🌐 Bant Genişliği

---

### 🌍 English

| Topic | Explanation |
|------|-------------|
| Bandwidth | Maximum data transfer capacity of a network |
| Unit | bps (bits per second), Mbps, Gbps |
| Meaning | How much data can be sent at the same time |
| Higher Bandwidth | Faster data transfer |
| Lower Bandwidth | Slower data transfer |
| Common Usage | Internet speed, API performance, servers |

---

### 🇹🇷 Türkçe

| Başlık | Açıklama |
|------|----------|
| Bant Genişliği | Bir ağın veri taşıma kapasitesi |
| Birim | bps, Mbps, Gbps |
| Anlamı | Aynı anda ne kadar veri gönderilebildiği |
| Yüksek Bant Genişliği | Daha hızlı veri aktarımı |
| Düşük Bant Genişliği | Daha yavaş veri aktarımı |
| Kullanım Alanı | İnternet hızı, API performansı, sunucular |

---

## 📊 Bandwidth vs Speed  
## 📊 Bant Genişliği vs Hız

### 🌍 English

| Concept | Explanation |
|------|-------------|
| Bandwidth | Road width (capacity) |
| Speed | How fast data moves |
| Example | Wide road allows more cars |

### 🇹🇷 Türkçe

| Kavram | Açıklama |
|------|----------|
| Bant Genişliği | Yolun genişliği (kapasite) |
| Hız | Verinin hareket etme hızı |
| Örnek | Geniş yol daha çok araba taşır |

---

## 🔌 Bandwidth in APIs  
## 🔌 API’lerde Bant Genişliği

### 🌍 English

| Area | Impact |
|------|--------|
| Large Responses | Uses more bandwidth |
| XML (SOAP) | Higher bandwidth usage |
| JSON (REST) | Lower bandwidth usage |
| Performance | Directly affected |

### 🇹🇷 Türkçe

| Alan | Etki |
|------|------|
| Büyük Response | Daha fazla bant genişliği |
| XML (SOAP) | Daha fazla bant tüketir |
| JSON (REST) | Daha az bant tüketir |
| Performans | Doğrudan etkilenir |

---

## 🎯 Summary / Özet

- **Bandwidth ≠ Speed**
- **SOAP (XML)** uses more bandwidth
- **REST (JSON)** is more bandwidth-friendly

- **Bant genişliği ≠ hız**
- **SOAP (XML)** daha fazla bant kullanır
- **REST (JSON)** daha verimlidir
